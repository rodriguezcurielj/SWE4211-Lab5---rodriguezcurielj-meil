This method will process a received network message. When it does this, it will calculate out and verify the checksum. If the checksum is correct, the contents will then be enqueued to the correct queue.

Parameters
receivedMessageThis is a reference to the received message structure, in network byte order.
Returns
The calculated checksum is returned.

  1. Declare a variable for the calculated checksum with a value of 0.

  2. Convert the security mode to host byte order before examining it. Every field that arrives from the network must be converted before it is used.

  3. If the security mode of the given message is 0 (unsecured), process it.

    1. Convert the message to host byte order. Do this by converting each individual structure element and placing it back in the structure.

    2. Calculate the XOR checksum of the data received, not including the checksum field.

    3. Call the printNetworkMessageToConsole method, which will print the contents of the message if the preprocessor setup is configured to print debug info out to the console. See debug_cfg.h and NetworkDebugLibrary.

    4. Verify that the calculated checksum matches the checksum that was transmitted.

      1. If the values match, the message is valid. Enqueue it to the right queue if it is a COMMAND_MSG_TYPE and the destination queue is valid. Destinations are numbered starting at 1.

  4. Return the calculated checksum.

bool NetworkManager::receiveNetworkMessage ( networkMessageStruct &  message)

This method receives one complete networkMessageStruct from the connected client.

Parameters

true if a complete message was received. false if the client closed the connection, only part of a message arrived, or an error occurred.

This method receives one complete networkMessageStruct from the connected client.

Parameters
messageThis is where the received message is stored. The fields are left in network byte order; conversion is done by processReceivedMessage() because it depends on the security mode of the message.
Returns
true if a complete message was received. false if the client closed the connection, only part of a message arrived, or an error occurred.

  1. Clear the message so that it never contains leftover memory.

  2. Read one structure's worth of bytes. TCP is a byte stream, so a single read could return only part of a message. MSG_WAITALL keeps waiting until the full size has arrived, unless the connection closes, an error occurs, or a signal interrupts the call.

  3. A negative return indicates an error. If a stop was requested, the error is expected (stopThreadExecution() shut the socket down), so only report it otherwise.

  4. A return of 0 means the client closed the connection.

  5. Anything short of a full structure means the stream is no longer aligned on message boundaries, so the connection cannot be trusted. Report it and treat it as a failure.

  6. A complete message was received.

◆ run()

void NetworkManager::run ( )
virtual

This is the run method for the class. It contains the code that is to run periodically on the given thread.

This is the run method for the class. It contains the code that represents the running thread.

  1. Create a socket file descriptor. The socket is an IPv4 TCP socket. If there is an error, indicate that the socket failed and return from the method.

  2. Call setsockopt to set up the options on the socket at the socket level. Each option is a separate ID, not a bit flag, so each needs its own call. SO_REUSEADDR allows the port to be reused immediately after the program exits; SO_REUSEPORT allows multiple sockets to bind to the same port. If there is an error, print out an error message, close the socket, and return.

  3. Clear the address structure so that any fields not set below (such as the sin_zero padding) are zero rather than leftover garbage.

  4. Set up the server address to use the IPv4 Internet protocols and to accept connections on any of this device's network interfaces. The port must be converted to network endianness.

  5. Bind the listening socket to the correct port. Only one socket can be bound to a given port at a time (unless SO_REUSEPORT is set by all of them). If there is a failure, print out an error, close the socket, and return.

  6. Mark the socket as a listening socket so clients can connect to it. This is done once; the socket remains in the listening state for its lifetime. The backlog is the number of connections that may wait before accept() is called. If there is an error, print it out, close the socket, and return.

  7. Loop so long as the thread is to continue running (i.e. a call to stop on this class has not occurred.)

    1. Reset addrlen. accept() both reads it (to know how much room is in their_address) and overwrites it, so it must be reset before every call.

    2. Block until a client connects. accept() returns a new socket for talking to that client; server_fd stays open to accept future clients.

    3. If accept failed:

      1. If a stop was requested, stopThreadExecution() shut the socket down to unblock accept(). This is expected, so leave the loop quietly.
      2. If the call was interrupted by a signal, simply try again.
      3. Otherwise, print the error and leave the loop.

    4. Turn on keepalive for the client connection so that the system periodically checks that an idle connection is still alive. This applies to the connected socket, not the listening socket. A failure here is not fatal, so only print a warning.

    5. Report out the IP address of the client that has connected to this server.

    6. So long as the client remains connected and the thread continues running:

      1. Receive one complete networkMessageStruct from the client.
      2. If a complete message arrived, process it. Otherwise the client closed the connection or an error occurred, so stop reading from this client.

    7. Close the connection to the client and mark the connected socket as invalid.

    8. Set the IP address of the connected client to zero and broadcast this out, indicating that no client is connected.

  8. Close the listening socket before the thread exits.
