DESCRIPTION

 This class is a controller for a light.  It runs as a periodic task and manages the light
 based upon incoming commands from its command queue and the state of a pushbutton.
 The brightness of the light is controlled with software pulse width modulation (PWM):
 during each period the light is turned on for a fraction of the period given by the duty
 cycle, and is then turned off for the remainder of the period.
