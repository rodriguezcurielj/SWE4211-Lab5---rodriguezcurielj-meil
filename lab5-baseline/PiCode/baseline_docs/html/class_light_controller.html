Detailed Description

A periodic task that controls a single light. On each period it processes any commands waiting on its command queue and then drives the light using software pulse width modulation (PWM), so that the fraction of each period the light is on sets its brightness.

void LightController::taskMethod ( )
virtual

This is the task method. The task method is invoked periodically, once every task period. Each invocation processes any waiting commands and then generates one period of the PWM signal for the light.

This is the task method. The task method is invoked periodically, once every task period. Each invocation processes any commands that are waiting on the queue and then generates one period of the PWM signal for the light.

  1. Start by determining whether any commands have arrived on the queue. If the queue has an item on it, dequeue it and process it as is applicable. Continue doing this until the queue is empty.

    1. There are one or more items on the queue. Remove the first item by dequeueing it.

    2. Determine which command was received and process it accordingly. Commands are bitmapped (see NetworkCommands.h), so test whether the bits for each command are set rather than comparing the whole value. Check for the commands in the order below. Any command that is not recognized, such as a broadcast message, is ignored.

      1. If the off command has been received:
        1. Record that the light should be turned off.
      1. If the on command has been received:
        1. Record that the light should be turned on.
      1. If a new PWM duty cycle has been received:
        1. Retrieve the requested duty cycle from the first parameter of the message.
        2. Check that the value is valid. The message uses a scale of 0 to 1000, where 1000 means 100% (see NetworkCommands.h). Ignore any value outside that range and keep the current duty cycle.
        3. If the value is valid, convert it to the percentage scale used by this class (0 to 100) and store it.

  2. Determine whether the light should be lit during this period. The light should be lit if the lamp is on (lampOn) or if the pushbutton is currently pressed. Remember that the pushbutton is active low. If the light should be lit, turn it on for the duty-cycle portion of the period and then turn it off.

    1. If the lamp is off and the pushbutton is not pressed, do nothing and simply end this iteration of the periodic task. The light is already off.

  3. Otherwise:

    1. The light should be lit at the current duty cycle, so turn it on by setting the output pin to the appropriate level. Remember that the light is active low.

    2. Calculate how long the light should stay on. This is the task period multiplied by the duty cycle percentage. The task period is in microseconds. Be careful with integer math: multiply before dividing so that the result is not truncated to zero.

    3. Sleep for the calculated amount of time while the light is on.

    4. Now turn the light off. It stays off for the rest of the period, until the next invocation of this task method.

  4. This ends the periodic task. It will execute again after the next period elapses, as long as the task is set up properly.
