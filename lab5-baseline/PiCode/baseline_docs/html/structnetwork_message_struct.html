Detailed Description

This structure represents a network message. A network message is transmitted via ethernet to the device and is processed.

uint32_t networkMessageStruct::message

This is the message that is to be sent.

◆ messageDestination

uint32_t networkMessageStruct::messageDestination

This is the destination. This is a numerical destination on the given device for the message (i.e. the queue). If the message type is Broadcast message, then this parameter is ignored and the message should be enqueued to any queue within the system.

◆ messageID

uint32_t networkMessageStruct::messageID

This is a unique ID for this message. It should always increase by 1 each time a message is sent. There never should be a duplicate message ID until the system rolls over after 2^32-1 messages, which should take a while we hope.
